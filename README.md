# VendFill 售货机补货

按货道容量、库存、在途量与最低陈列面计算**有效缺口**，生成不超容量、非负的补货单。

有效缺口口径：

- 现网缺口 = 容量 − 库存 − 在途。
- 当库存 **低于** 最低陈列面（陈列面 > 0）时，有效缺口 = 现网缺口 + 陈列面兜底量
  `max(0, 陈列面 − 库存 − 在途)`，再夹到 `[0, 容量]`（仍不为负、补量仍不超过容量约束）。
- 库存已达陈列面及以上，或陈列面留空 / 0 时，退回现网缺口。
- 因陈列面抬高而出现正补量的道标记为「待补」，与「满仓」互斥。

在货道页保存最低陈列面时，若存在最新补货单，会同事务按新有效缺口**就地重写该单**
（不新建单、不回刷历史单）；保存失败则陈列面与最新单一并回滚。陈列面大于容量拒绝保存，
货道、最新单、汇总三处均不动。

技术栈：Python 3.12 / FastAPI / SQLAlchemy / PostgreSQL / Vue 3 / TypeScript / Vite

## 启动

```bash
docker compose up --build
```

| 服务 | 地址 |
| --- | --- |
| 前端 | http://localhost:4800 |
| API | http://localhost:9800 |
| API 文档 | http://localhost:9800/docs |
| Postgres | localhost:5449 |

健康检查：`GET http://localhost:9800/api/health`

## 使用说明

1. 在「点位」「货道」查看售货机布局与库存，并在货道卡上登记最低陈列面（件）。
2. 在「销量」了解近期出货。
3. 打开「补货单」按有效缺口生成建议补货量。
4. 在「满仓」「汇总」查看已满货道与补货合计。
